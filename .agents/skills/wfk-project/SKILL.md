# WFK project

Resolve the repository root as `../../..` from this skill directory.
Read `<root>/05_System/Workflows/REF - Codex Execution Policy.md` and
`<root>/05_System/Workflows/REF - Project Lifecycle.md`.

Read the project lifecycle contract first. Locate the parent/subproject and existing active artifacts. Route to the first missing stage: wfk-create-spec, wfk-review-spec, wfk-plan-spec, wfk-implement. Interview before building when scope is incomplete. Continue authorized stages automatically, but stop for missing material decisions or a narrower user request. On resume use saved plan/PIC state. Do not treat a request for action as permission to skip the specification.
